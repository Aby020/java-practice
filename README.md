# 📌 Project Overview

This repository contains Java programs created while practicing **Core Java** concepts. Each program focuses on a specific topic, helping build a strong foundation in object-oriented programming, data structures, algorithms, and problem-solving techniques.

The programs are organized into topic-based folders for easier navigation and learning.
